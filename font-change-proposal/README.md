# Font-change proposal — evidence images

Evidence for a request to the Pebble translations team to change the approved zh_Hans (Simplified Chinese) font from Firefly Sung (fireflysung.ttf) to Noto Sans SC.

- `clipping-ab-compare.png` — the same Settings screen on the same Pebble Time 2: official zh_Hans pack (left, tops of characters clipped) vs this community pack with Noto Sans SC (right, intact).
- `official-pack-clipping-photo.jpg` — official pack screenshot, original.
- `official-pack-clipping-zoom.png` — zoomed crop of the official pack screenshot.
- `own-pack-same-screen.jpg` — community pack screenshot, original.
- `font-compare-legibility.png` — 1-bit renders of both fonts at 14/18/24/28/36 px.
- `font-compare-glyphforms.png` — glyph-form comparison for common characters.
- `font-compare-bold.png` — bold comparison (Firefly ships a single weight).
